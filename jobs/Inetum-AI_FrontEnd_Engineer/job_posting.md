## Description

Healthcare project. Design, build and evolve the digital experiences of **Casiopea** with React, ensuring usability, performance, accessibility and maintainability, and adding advanced AI capabilities, intelligent assistants and conversational experiences for healthcare professionals, administrative staff and patients.

## Minimum requirements: Senior React (TypeScript + Vite + MFE)

- **Experience:** 5+ years frontend, 3+ years React in production; large enterprise or SaaS apps; multidisciplinary teams; frontend architecture, key technical decisions, mentoring.
- **Advanced React:** hooks (core and custom), modern lifecycle, compound components, hooks pattern, headless components; state with Redux Toolkit or Zustand; side effects; memoization, code splitting (React.lazy, Suspense), render performance.
- **TypeScript:** complex generics, typing hooks and HOCs, API domain modelling, union types, narrowing, inference.
- **Vite (production):** custom plugins, aliases and module resolution, differences from Webpack, bundle optimization, dev and build performance.
- **Microfrontends (key requirement):** real MFE architectures in production. Module Federation (Webpack or Vite Federation), Single-SPA, Web Components. Communication via event bus, props and shared state, custom events. Shared libs, versioning, isolation vs reuse. Shell/container app, independent deployment per MFE, decoupled CI/CD. Known problems: dependency deadlocks, duplicated React, runtime performance, team coordination.
- **Data:** REST and/or GraphQL; caching, revalidation, data sync between MFEs.
- **UI:** CSS from the UI team's designs.
- **Testing:** Jest or Vitest, React Testing Library; isolating tests and mocking external MFEs in MFE setups.
- **Architecture:** scalable, modular frontend; clean code; error boundaries; distributed logging.
- **Ecosystem:** advanced Git, CI/CD per MFE, monorepos (Nx, Turborepo), ESLint.
- **Security:** tokens shared between MFEs, XSS protection, SSO in MFE architecture.

## Highly valued

- Next.js (SSR with MFEs), edge rendering
- Observability: centralized logs, Datadog, Sentry
- Feature flags
- Monolith to MFE migrations
- AI: prompt engineering, RAG, MCP, LLMs, function calling, AI agents, vector search, semantic search, responsible AI

Communication between teams, defining contracts between applications, global architecture vision, ownership of functional domains.
