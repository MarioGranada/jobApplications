## About Stripe

Financial infrastructure platform for businesses. Millions of companies use Stripe to accept payments, grow revenue and accelerate new business opportunities. Mission: increase the GDP of the internet.

## About the team: UI Platform (Sail)

Sail builds the foundations for Stripe's Dashboard and many other Stripe UIs, and owns Stripe's design system, helping engineers create consistent, accessible, performant, high-quality experiences at scale. They build reusable components, design tokens, theming, documentation and developer tooling used by engineers and designers across Stripe.

Two current focus areas:
1. **Sail for Agents**: generation infrastructure, documentation systems, agent integrations and automated quality checks that help AI coding agents build high-quality Stripe interfaces safely and consistently at scale.
2. Evolving the visual language of the Dashboard while modernizing its underlying codebase.

## Responsibilities

- Take end-to-end ownership of software projects: scoping, design, implementation, testing, rollout
- Build and maintain accessible, performant, well-tested components, themes and frontend APIs used across Stripe
- Build tooling, documentation and automated quality checks that help engineers and AI coding agents use Sail effectively
- Partner with product designers and engineers to turn recurring UI patterns into reusable design-system capabilities
- Help evolve the Dashboard's visual language while modernizing its codebase and migrating legacy UI patterns
- Improve accessibility, internationalization, observability, performance, reliability and developer experience of the design system
- Contribute code reviews, technical discussions and documentation

## Minimum requirements

- Fluency in AI-assisted and agentic development tools day to day, including critically reviewing, validating and improving generated code
- 2+ years of professional frontend engineering experience
- Strong knowledge of modern frontend technologies, browser fundamentals, responsive design and accessibility
- Ability to independently scope and deliver open-ended frontend projects with limited oversight
- Strong problem-solving and debugging, with attention to testing, maintainability and UX quality
- Strong written and verbal communication; collaboration with designers and product engineers

## Preferred qualifications

- Developer tooling: build tools, package managers, codemods, lint rules, large monorepos
- Building tools, integrations or automated evaluation and quality systems for AI coding agents
