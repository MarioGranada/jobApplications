As a Backend Engineer specializing in Elixir, you will build real-time, concurrent backends using the Phoenix framework. You will leverage functional programming principles to create highly scalable and fault-tolerant systems that handle demanding workloads with low latency.

What You'll Do


 Design and develop robust backend services and APIs using Elixir and the Phoenix framework.
 Implement efficient data persistence and complex queries using Ecto and PostgreSQL.
 Build interactive, real-time features using Phoenix LiveView and OTP patterns.
 Architect concurrent systems using GenServers and supervision trees to ensure high availability.
 Optimize application performance and maintainability through functional programming best practices.
 Collaborate with cross-functional teams to deliver reliable, distributed production systems.


What We Are Looking For


 4+ years of experience in Backend Engineering with a focus on functional programming.
 Proven expertise in developing real-time, concurrent systems using Elixir and the Phoenix framework.
 Deep understanding of OTP patterns, GenServers, and the BEAM virtual machine.
 Proficiency in working with Ecto and PostgreSQL for data persistence and management.
 Experience implementing modern interactive web features using Phoenix LiveView.
 Advanced proficiency in English.
