Senior React + TypeScript Developer at BairesDev




We are looking for a Senior React + TypeScript Developer to join our development team. In this role, you'll be responsible for creating sophisticated frontend applications, making architectural decisions, and mentoring junior developers. You'll leverage your deep expertise in React and TypeScript to deliver high-performance, scalable solutions.




What You'll Do:




- Design and develop sophisticated frontend applications using React and TypeScript.

- Implement and optimize state management solutions using Redux or Context API.

- Create reusable components and libraries for future use.

- Integrate with RESTful APIs and backend services.

- Lead code reviews and establish best practices for the frontend team.

- Architect scalable solutions that ensure optimal performance and maintainability.




What we are looking for:




- 5+ years of experience with React.

- Strong proficiency in TypeScript.

- Experience with state management using Redux and/or Context API.

- Knowledge of RESTful API integration.

- Experience with Node.js.

- Familiarity with SQL databases, particularly PostgreSQL.

- Advanced level of English.




Nice to have:




- Experience with AWS ecosystem services.

- Knowledge of containerization with Docker.

- Familiarity with AWS Bedrock.

- Experience with Infrastructure as Code.
