Senior Fullstack Javascript Engineer (React + Node) at BairesDev




We are looking for a Senior Fullstack Javascript Engineer specializing in React and Node.js to join our development team. In this role, you'll be responsible for end-to-end application development, making architectural decisions, and ensuring high-quality implementation across both frontend and backend systems.




What You'll Do:




- Architect and develop full-stack applications using React for frontend and Node.js for backend.

- Design and implement RESTful APIs for robust service integration.

- Create optimized state management solutions using Redux or Context API.

- Build and maintain database integrations with SQL databases, particularly PostgreSQL.

- Lead code reviews and establish coding standards across the development team.

- Drive technical decisions and implement scalable, maintainable solutions.




What we are looking for:




- 5+ years of experience with JavaScript/TypeScript development.

- Strong expertise in React frontend development.

- Proficiency in Node.js backend development.

- Experience with RESTful API design and implementation.

- Knowledge of state management solutions (Redux/Context API).

- Familiarity with SQL databases, particularly PostgreSQL.

- Advanced level of English.




Nice to have:




- Experience with AWS ecosystem services.

- Knowledge of containerization with Docker.

- Familiarity with AWS Bedrock.

- Experience with Infrastructure as Code.
