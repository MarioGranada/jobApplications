Senior React Engineer at BairesDev




As a Senior React Engineer, you will build production-grade web applications using TypeScript and modern hooks. You will align user interface designs with technical requirements, ensuring high performance and a seamless component-driven architecture.




What You'll Do:




- Design and develop responsive UI components using React, TypeScript, and modern hooks.

- Implement robust state management strategies using Redux, Zustand, or the Context API.

- Collaborate with designers and backend teams to translate wireframes into polished, production-ready experiences.

- Optimize frontend applications for maximum performance, scalability, and cross-browser reliability.

- Drive code quality through rigorous peer reviews, comprehensive testing, and modern styling practices.

- Connect frontend interfaces to backend systems using RESTful APIs or GraphQL for efficient data flow.




What we are looking for:




- 4+ years of experience in Software Engineering with a focus on Frontend development.

- Proven expertise in building production-grade applications using React and TypeScript.

- Deep understanding of modern hooks, component-driven architecture, and state management.

- Proficiency in UI styling using Tailwind CSS or styled-components.

- Experience with testing frameworks such as Jest or Vitest and integrating REST/GraphQL APIs.

- Advanced proficiency in English.
